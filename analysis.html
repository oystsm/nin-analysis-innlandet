Introduction

This project was created as a way for me to further develop my GIS and spatial analysis skills, building upon what I learned during my time as a master’s student in bioscience at the University of Oslo. The project demonstrates a basic spatial analysis workflow in R using “nature type” data based on the Norwegian Nature in Norway (NiN) classification system. The goal was simple: identify and summarize mapped nature types within a selected planning area in Innlandet county.

Methods

First, the coordinate reference system (CRS) and spatial extent of the dataset were inspected to ensure that all layers used compatible spatial projections. The center point of the dataset extent was then identified and used to define a smaller planning area for analysis and visualization.

A rectangular planning area was created as an sf polygon object around the selected center coordinates. Spatial intersection analysis was then performed using st_intersection() to clip nature type polygons to the planning area, only retaining the portions of mapped nature types located within the analysis boundary.

The area of each resulting polygon was calculated using st_area() and converted from square meters to hectares. Areas were then summarized by NiN nature type using functions from the dplyr package.

In order to create a easily interpretable map, only the nature types covering the largest geographical area were used in visualization.

Finally, the results were visualized using ggplot2 and ggspatial to create a clean map suitable for a portfolio, showing the spatial distribution of mapped nature types within the selected planning area.

# Create a simulated 10km x 10km planning area
plan_coords <- matrix(
  c(
    x_mid - 5000, y_mid - 5000,
    x_mid + 5000, y_mid - 5000,
    x_mid + 5000, y_mid + 5000,
    x_mid - 5000, y_mid + 5000,
    x_mid - 5000, y_mid - 5000
  ),
  ncol = 2,
  byrow = TRUE

plan_polygon <- st_polygon(list(plan_coords))

plan_sf <- st_sf(
  geometry = st_sfc(
    plan_polygon,
    crs = st_crs(natur)

natur_klippet <- st_intersection(natur, plan_sf)

Discussion

The spatial analysis identified a range of mapped nature types within the the selected planning area. Within the 10km \(\times\) 10km planning area, mapped nature type polygons covered approximately 414 hectares, corresponding to about 4.1\(\%\) of the total area. This reflects the selective and time consuming nature of ecological field mapping, where the standards and focus of the mapping procedure is set by the project client.

There are four types that stand out in terms of geographical coverage: Kalkfattig og intermediaer fjellhei, leside og tundra (347 ha), Boreal hei (36.3 ha), Naturbeitemark (16.3 ha) and Hogreliggende og nordlig nedborsmyr (12.1 ha). Together, these account for 411.7 hectares, corresponding to 99.4\(\%\) of the total mapped nature type area.

This project provided practical experience working with spatial ecological data in R and served as a refresher on GIS workflows involving NiN datasets. In addition to the technical aspects of the spatial analysis, the project also highlighted several important considerations in cartographic visualization, including the selection of an appropriate planning area, decisions regarding which spatial information to include, and the importance of effective color palette design for communicating ecological patterns in a clear way.
